# 🔐 BinC (Binary Cipher)

**BinC** — это кастомный алгоритм шифрования текста на основе координатных сеток (принцип квадрата Полибия). Изначально разработан для безопасной передачи записок, но вырос в полноценный формат шифра.

**BinC** is a custom text encryption algorithm based on coordinate grids. Originally designed for passing secure notes, it evolved into a full-fledged custom cipher format.

## 🛠 Возможности (Features)

- **Двуязычность**: Автоматически определяет русский или английский текст и применяет нужную сетку (`4x7` для EN, `6x6` для RU).
- **Умный регистр**: Использует префикс `=^=` для выделения конкретных заглавных букв, скрывая имена собственные от посторонних глаз.
- **Сжатие повторов**: Повторяющиеся буквы кодируются через `"1`, `"2` или `"!` для экономии места.
- **Пунктуация**: Спецсимволы оборачиваются в скобки вида `['.']` или `['!']`.

## 🔬 Как это работает

Шифр использует координаты `{колонка, строка}` для каждой буквы. Чтобы строка выглядела как единый поток данных, используются спецтеги:
- `%-%` — пробел.
- `=^=` — следующая буква заглавная.
- `<EN>` / `<RU>` — тег языка в начале строки (говорит расшифровщику, какую сетку использовать).
- `{x,y"!}` — буква повторяется 3 и более раз.

## 🚀 Как запустить

Для запуска не нужно ничего устанавливать. Используй любой онлайн-компилятор Python (например, Koddo или OneCompiler).

1. Скопируй код из файла `main.py`.
2. Вставь его в компилятор.
3. В самом низу кода найди строку `user_text = "ur text"` и замени `ur text` на своё сообщение.
4. Нажми **Run**.
